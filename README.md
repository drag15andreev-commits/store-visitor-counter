# Подсчёт посетителей на изображениях

Учебное Flask-приложение: YOLOv8n обнаруживает людей на загруженном изображении, SQLite хранит журнал обработок, PDF и Excel выгружают журнал за выбранный период.

## Запуск в Windows

Нужен Python 3.9–3.12; проверено на Python 3.9.13. Распакуйте проект и запустите `start.bat`. При первой установке зависимостей нужен интернет. Откройте **http://127.0.0.1:5000**. Окно сервера должно оставаться открытым; остановка - Ctrl+C.

Ручной запуск:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

При первой обработке Ultralytics загружает `yolov8n.pt`, если его нет рядом с `app.py`. Можно скопировать свой существующий файл модели в эту папку. Файл весов не включён в исходники. На компьютере проверки модель находилась отдельно; автоматическая загрузка весов не проверялась.

Если порт занят: в PowerShell задайте `$env:PORT=5001`, затем запустите приложение и откройте адрес с портом 5001.

## Работа с отчётами

1. Загрузите изображение на главной странице.
2. Откройте «История и отчёты».
3. При необходимости задайте даты и нажмите «Применить».
4. Нажмите «Скачать PDF» либо «Скачать Excel».

Выгрузка содержит номер обработки, дату и время, исходное имя файла, число людей на снимке, количество обработок и сумму обнаружений. Сумма по снимкам **не является числом уникальных посетителей**. Начальная и конечная даты включаются в выборку. Без дат выгружается весь журнал; пустой период создаёт корректный файл без записей. Время записывается по локальным часам компьютера.

PDF использует Unicode-шрифт Arial из Windows. Для Linux поддержан DejaVu Sans; другой шрифт можно указать через переменную `REPORT_FONT` (полный путь к TTF). XLSX сохраняет имена файлов текстом, включая значения с начальным `=`.

## Файлы

- `app.py` - маршруты, проверка загрузки, SQLite, фильтры и скачивание отчётов.
- `detector.py` - загрузка YOLO и обработка изображения.
- `reports.py` - создание PDF и XLSX.
- `templates/` - главная страница и история с кнопками экспорта.
- `static/style.css` - оформление интерфейса.
- `tests/test_app.py` - 13 автоматических проверок.
- `data/` - создаваемая при запуске база и изображения результатов, исключены из Git.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Автоматические тесты используют временную базу и замену детектора: проверяют приложение, экспорт, данные XLSX, даты, ошибки и сохранность. Они не измеряют точность YOLO. Отдельная интеграционная проверка настоящей YOLOv8n на исходном изображении с четырьмя людьми дала результат 4; экспорт PDF/XLSX содержал то же значение. Дата повторной проверки - 03.11.2026. Обобщать этот результат на другие изображения нельзя.

## Перенос старой истории

Новая версия хранит данные в `data/history.db` рядом с проектом. Старую базу автоматически не изменяет. Чтобы перенести историю, остановите оба сервера, сохраните резервную копию, скопируйте старый `history.db` в `data/history.db`, а файлы из прежней `static/results` — в `data/results`. Поля таблицы `requests` совместимы. Не заменяйте новую базу, если уже внесли в неё нужные записи, без предварительного объединения данных.

## Ограничения

Приложение локальное, без авторизации и видеоаналитики; слушает только 127.0.0.1, отладчик выключен. Ограничение загрузки - 8 МиБ и 20 млн пикселей. Экспорт большого журнала выполняется в памяти. Массовые и параллельные запросы не испытывались.

Используются сторонние библиотеки с собственными лицензиями. Для Ultralytics и весов YOLO действуют условия их правообладателя; см. https://www.ultralytics.com/license .
